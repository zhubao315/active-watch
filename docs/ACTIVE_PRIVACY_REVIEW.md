# ACTIVE 隐私复审（2026-11-18）

结论：本轮改动**没有扩大数据公开范围，没有修改任何原始数据**。四仓原有的 `ACTIVE_PRIVACY_AUDIT.md` 与 `DATA_PUBLICATION.md` 继续有效。

## 1. 本轮变更的隐私影响

| 变更 | 影响 |
|---|---|
| 新增 `data-watermark.json` | 只暴露活动条数、最近活动日期、SHA-256、构建版本。不含坐标、轨迹、心率或健康指标。 |
| 相关性新增 ρ/p/q | 只使用既有健康指标的聚合统计；不新增个体级数据。 |
| 巡检 API 权限增加 `actions: read` | 只读工作流运行元数据，不增加写权限。 |
| 数据基线文件 | 只记录计数与阈值，无个人信息。 |

## 2. 既有风险（未变化）

- GPS 起终点：轨迹按年公开，起终点可定位住所/常用地点。`DATA_PUBLICATION.md` 已记录该选择。
- Git 历史不可撤销：历史 FIT/GPX/JSON 一旦提交无法真正删除。
- 健康数据：睡眠/HRV/压力等按个人基线公开；无医学诊断输出。
- Token：`ACTIVE_STATE_TOKEN` 仅用于配额账本写入，不进入前端产物。

1. 发布层可配置化：起终点模糊化半径、健康指标公开白名单，输出到独立发布产物，不改原始库。

## 4. 验收原则

任何隐私策略调整必须：不改原始数据、采用可配置发布层、可回滚、并在四仓文档中同步说明。
